# Scam drill

An interactive training exercise for school staff in Aotearoa New Zealand. It runs
two scams that reach teachers, and it lets the room make the choice and see the result.

**Live page:** https://twofivefivedev.github.io/scam-drill/

## The two scams

1. **The fake login page** — an email about a full mailbox sends you to a page that
   copies your staff portal.
2. **The bank text and the code request** — a payment alert arrives by text, and a
   phone call follows it to ask for your one-time code.

Each scam holds five warning signs. Click them in the message to mark them. Every
ending shows what happened, the five steps to take afterwards, and where to report
in New Zealand.

## This is a drill

The school, the bank, the senders, the callers and every web address are invented.
Nothing here imitates a real organisation.

**No data is collected.** The password fields never read, keep, or send what you
type. The script counts the characters, clears the field, and discards them. There
is no server, no form action, and no network request of any kind.

## Running it

Open `index.html` in any browser, or use the live page above. One file, no build
step, no dependencies.
